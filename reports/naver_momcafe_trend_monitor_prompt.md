네이버 맘카페 트렌드를 매일 조사해서 대시보드를 갱신하고, 로그를 남기고, 카카오톡으로 요약을 보내는 작업이다. 아래 순서대로 진행한다.

## 배경
사용자(joonho73@gmail.com)는 네이버 주요 "전국 단위" 맘카페(맘스홀릭 베이비, 레몬테라스, 도치맘카페, [영유나라] 영어유치원 교육정보 맘카페, 쌍둥이맘 모여라 등)에서 아래 3개 주제의 트렌드를 매일 확인하고, 그 링크를 카카오톡으로 받고 싶어한다:
1. 미디어/콘텐츠/IPTV/OTT
2. 육아용품/쇼핑
3. 교육/학원

**중요 — 지역 콘텐츠 제외 원칙**: 특정 지역에 한정된 맘카페(카페명에 지역명이 들어간 "OO맘카페", "부산맘카페", "경기북부맘스쿨", "킨더맘"(창원) 등 특정 시/구/동 단위 카페)나 특정 지역 이벤트·시설을 다루는 글은 제외한다. 해외 교민 대상 카페(예: 일본맘)도 제외한다. 대신 전국 단위로 활동하는 맘카페나, 지역에 매이지 않는 육아·재테크·정책 정보 카페의 글을 우선 선별한다.

**중요 — 카카오톡에 넣는 링크는 반드시 Send(send.co)를 쓸 것**: claude.ai 아티팩트 링크는 비공개+로그인 필요라 카카오톡 인앱 브라우저에서 열리지 않는다. 대시보드는 Send MCP(서버 id `8d709be1-3ea1-4e05-9885-f54116ead5eb`)의 `GetDocument`/`EditDocument`로 게시한다. 이 문서의 send.co shareId는 `SLtEZ3qt` (URL: https://www.send.co/a/SLtEZ3qt) 이며, 매번 이 shareId를 EditDocument로 덮어써서 같은 링크를 유지한다.

**⚠️ 과거 실행 이력 — 반드시 읽을 것**: 이 작업은 2026-07-22부터 매일 실행되어 왔지만, 실제로는 send.co 문서와 로그 파일이 2026-07-22 이후 단 한 번도 갱신되지 않은 것이 2026-07-29에 발견되었다. 원인으로 추정되는 것은 EditDocument를 여러 개의 작은 조각(old_string)으로 나눠 호출하도록 지시했던 이전 버전의 프롬프트였다 — 문서 안의 SVG 좌표, 특수문자, 줄바꿈 등이 정확히 일치하지 않으면 EditDocument 전체가 실패하고(atomic), 이후 단계(로그 기록, 카카오톡 전송)까지 조용히 건너뛰어졌을 가능성이 높다. 이번 버전은 이 문제를 피하기 위해 **EditDocument를 단일 호출·단일 큰 블록 치환**으로 단순화했다. 아래 5~6단계를 반드시 이 방식 그대로 따르고, 만약 EditDocument가 실패하면 절대 조용히 넘어가지 말고 원인(old_string 불일치 등)을 다시 확인해 재시도한 뒤, 그래도 실패하면 완료 보고(9단계)에 실패 사실과 에러 메시지를 반드시 남긴다.

이 작업이 남기는 로그(momcafe_trend_log.jsonl)는 별도로 등록된 "2주 리뷰"(naver-momcafe-biweekly-review, 매월 1일·15일)와 "월간 리뷰"(naver-momcafe-monthly-review, 매월 1일) 작업이 읽어서 중기 트렌드를 종합하는 데 사용하므로, 로그 기록 단계를 빠뜨리지 않는다.

## 데이터 수집
1. ToolSearch로 다음 도구를 로드한다(만약 "select:" 쿼리로 아래 정확한 이름이 하나라도 로드 실패하면, 곧바로 query="네이버 카페 검색 데이터랩"처럼 키워드 검색으로 재시도해서 현재 연결된 Naver Search MCP 서버의 실제 도구명을 찾아 사용한다 — 서버 id가 바뀌었을 수 있다): "select:mcp__7bd9f4eb-0282-4656-94ea-f7aad88c7965__NaverSearch-search_cafearticle,mcp__7bd9f4eb-0282-4656-94ea-f7aad88c7965__NaverSearch-datalab_search,mcp__7bd9f4eb-0282-4656-94ea-f7aad88c7965__NaverSearch-get_current_korean_time,mcp__7bd9f4eb-0282-4656-94ea-f7aad88c7965__KakaotalkChat-MemoChat,mcp__8d709be1-3ea1-4e05-9885-f54116ead5eb__EditDocument,mcp__8d709be1-3ea1-4e05-9885-f54116ead5eb__GetDocument"
2. get_current_korean_time으로 오늘 날짜를 확인한다.
3. search_cafearticle (sort=date, display=15)로 아래 쿼리를 각각 조회한다:
   - 주제1(미디어/OTT): "인터넷 결합상품 후기", "OTT 구독 아이", "넷플릭스 디즈니플러스 아이"
   - 주제2(육아용품): "유모차 추천", "카시트 추천", "육아용품 신상"
   - 주제3(교육/학원): "영어유치원 후기", "학원비 부담", "엄마표 영어"
   각 주제별로 결과 중 위 "지역 콘텐츠 제외 원칙"에 해당하는 항목을 걸러낸 뒤, 남은 항목 중 전국 단위 콘텐츠를 주제별 4~5개씩 대표 게시글(제목, 카페명, 한줄 요약, 링크)로 고른다. 부족하면 카드 수를 3개로 줄여도 된다.
4. datalab_search로 최근 13주(오늘 기준 -91일 ~ 오늘, timeUnit=week) 트렌드를 조회한다. keywordGroups:
   - {"groupName":"IPTV_OTT","keywords":["IPTV","OTT구독"]}
   - {"groupName":"유아용품","keywords":["유모차","카시트"]}
   - {"groupName":"영어유치원_사교육","keywords":["영어유치원","사교육비"]}
   각 그룹의 첫 주 대비 마지막 주 증감률(%)과 13개 주간 ratio 값을 기록한다.

## 리포트 작성 (Send 문서 갱신 — 반드시 단일 블록 치환 방식)
5. GetDocument(shareIdOrUrl="SLtEZ3qt")로 현재 문서 전체를 읽는다.
6. EditDocument를 **정확히 1번, edits 배열에 항목 1개**로 호출한다:
   - old_string: GetDocument 응답에서 `<body>` 여는 태그 바로 다음부터 `</style>` 닫는 태그 바로 앞까지의 전체 텍스트를 **한 글자도 고치지 않고 그대로 복사**해서 넣는다(새로 타이핑/재구성하지 말 것 — GetDocument 출력에서 그대로 잘라 붙여넣기).
   - new_string: 그 자리를 대체할 새 콘텐츠 전체(헤더+summary-row+3개 board 섹션+footer, 그리고 그 뒤에 `<style>...</style>` 전체)를 새로 작성해 넣는다. 디자인(CSS 변수, 레이아웃 구조)은 old_string에 있던 것과 동일하게 유지하고, 다음만 바꾼다: 조회 기간 날짜, summary-row 3개 chip의 증감률/설명, 각 board의 SVG 스파크라인(13개 점, x는 0~150을 12등분, y는 46 기준 그룹 내 min~max를 0~45로 정규화, 값이 클수록 위로/작은 y, 마지막 점 circle 강조 — 직전 대비 하락이면 var(--down) 상승이면 var(--up)), 최근 주 상대지수 숫자, insight 텍스트, cards(전국 단위 콘텐츠만, 오늘 새 글 우선).
   - replace_all은 false로 둔다(구간이 문서 전체에서 유일하므로 기본값으로 충분).
   - 이 호출이 실패하면(문자열 불일치 에러 등) GetDocument를 다시 호출해 최신 바이트를 확보하고 old_string을 다시 정확히 복사해 1회 재시도한다. 그래도 실패하면 8~9단계는 진행하되 9단계 보고에 "Send 문서 갱신 실패"를 명시한다.

## 리뷰용 로그 기록 (중요 — 빠뜨리지 말 것)
7. `D:\my agent\reports\momcafe_trend_log.jsonl` 파일을 Read로 읽는다(파일이 없다는 오류가 나면 빈 내용으로 간주). 기존 내용 뒤에 오늘자 로그 한 줄(줄바꿈으로 구분된 압축 JSON, 마지막에 개행 포함)을 추가한 전체 내용을 Write로 같은 경로에 덮어쓴다. 형식:
   {"date":"YYYY-MM-DD","media":{"ratio":<최근주 IPTV_OTT ratio>,"deltaPct":<13주 증감률>},"goods":{"ratio":<최근주 유아용품 ratio>,"deltaPct":<13주 증감률>},"education":{"ratio":<최근주 영어유치원_사교육 ratio>,"deltaPct":<13주 증감률>},"headlines":{"media":["제목 (카페명)", "제목 (카페명)"],"goods":["..."],"education":["..."]}}
   이미 오늘 날짜로 기록된 줄이 있으면 새로 추가하지 말고 그 줄을 갱신된 값으로 교체한다.

   링크가 잘리지 않도록 다른 부분을 줄여서라도 200자 이내를 반드시 지킨다.
