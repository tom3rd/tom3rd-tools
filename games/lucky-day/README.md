# Lucky Day

카드를 뒤집어 토큰을 두 배로 불리는 케주얼 더블업 게임.

## 플레이 방법

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다 (외부 빌드 도구 불필요).

1. 광고 시청(연출) 후 100 토큰으로 시작합니다.
2. 스테이지마다 카드 수가 2, 3, 4, 5, 6장으로 한 장씩 늘어나며(1~5단계, 최대 5단계), 배율도 ×2, ×3, ×4, ×5, ×6으로 함께 커집니다. 그중 한 장이 행운의 카드입니다.
3. 행운의 카드를 고르면 해당 단계 배율만큼 토큰이 늘어나고, "다음 스테이지로 도전"할지 "여기서 적립"할지 선택할 수 있습니다.
4. 다른 카드를 고르면 이번 판의 토큰을 모두 잃습니다.
5. 5단계(카드 6장, ×6배율)를 클리어하면 자동으로 적립되며 게임이 마무리됩니다.
6. 언제든 픽 전에 "지금 적립하기"로 현재 토큰을 지갑에 담아 확정할 수 있습니다. 지갑 잔액은 브라우저 `localStorage`에 저장되어 다음 방문에도 유지됩니다.
7. "교환소"에서 지갑 토큰으로 교환 가능한 리워드 목록을 볼 수 있습니다 (실제 교환 연동은 미구현 프로토타입 상태입니다).

## 디자인

- 밝은 민트 배경에 코랄·탠저린·민트·스카이 톤을 쓴 캔디 컬러 팔레트로 톤앤매너를 통일했습니다.
- 표제부는 둥근 한글 디스플레이 서체 "Jua", 본문은 "IBM Plex Sans KR"을 사용해 한글도 예쁘게 렌더링됩니다.
- 카드 뒷면은 4가지 그라디언트 색상이 순환하며, 가운데 원형 배지와 대각선 광택 효과로 카드 느낌을 살렸습니다.
- 카드 그리드는 `flex-wrap` 기반으로 한 줄에 최대 3장씩 자동으로 중앙 정렬되어, 2~6장 어떤 개수에서도 균형 잡힌 배열을 보여줍니다.
- 상단 HUD(로고 · 지갑 · 교환소)를 얇게 고정하고 본문은 카드형 패널 하나로 모아, 모바일 화면에서 스크롤 없이 한눈에 보이도록 구성했습니다.

## 참고

- 순수 HTML/CSS/JS로 작성되어 별도 빌드나 서버 없이 정적으로 서빙할 수 있습니다.
- 실제 서비스로 발전시키려면 광고 SDK 연동, 서버 측 토큰/지갑 검증, 실제 리워드 지급 로직이 필요합니다.
