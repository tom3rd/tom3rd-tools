# Lucky Day

카드를 뒤집어 토큰을 두 배로 불리는 케주얼 더블업 게임.

## 플레이 방법

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다 (외부 빌드 도구 불필요).

1. 광고 시청(연출) 후 100 토큰으로 시작합니다.
2. 스테이지마다 카드 수가 2, 4, 6, 8, 10, 12장으로 늘어나고(최대 12장), 그중 한 장이 행운의 카드입니다.
3. 행운의 카드를 고르면 토큰이 두 배가 되고 다음 스테이지로 진행합니다.
4. 다른 카드를 고르면 이번 판의 토큰을 모두 잃습니다.
5. 언제든 "지금 교환하기"로 현재 토큰을 지갑에 담아 확정할 수 있습니다. 지갑 잔액은 브라우저 `localStorage`에 저장되어 다음 방문에도 유지됩니다.
6. "교환소"에서 지갑 토큰으로 교환 가능한 리워드 목록을 볼 수 있습니다 (실제 교환 연동은 미구현 프로토타입 상태입니다).

## 참고

- 순수 HTML/CSS/JS로 작성되어 별도 빌드나 서버 없이 정적으로 서빙할 수 있습니다.
- 실제 서비스로 발전시키려면 광고 SDK 연동, 서버 측 토큰/지갑 검증, 실제 리워드 지급 로직이 필요합니다.
